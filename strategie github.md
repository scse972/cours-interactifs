📋 Récapitulatif des règles métier
Condition	Affichage du bouton Téléverser	Action au clic
Non authentifié	Désactivé (ou grisé)	Demande d'authentification
Site source non vérifié	Désactivé	Demande de vérifier source
Authentifié + Source OK + Site distant inexistant	Actif (Créer)	Fork + activation Pages
Authentifié + Source OK + Site distant existant	Actif (Mettre à jour)	Synchronisation du fork
🔧 Correspondance champ par champ
Ta maquette	Ma proposition
Site distant → Adresse	URL du site final (sur GitHub Pages)
Site distant → Vérifier	Check que l'URL finale répond
Déploiement Git (nouvelle version)	Authentification GitHub
Site source → Dépôt Git	URL du repo source à copier
Site source → Branche	Branche à copier (main par défaut)
Site source → Vérifier	Check que le repo source existe
Destination → Nom du site	Nom du fork sur son compte
Téléverser	Bouton unique (création ou mise à jour)

1. Authentification GitHub : Token manuel ou OAuth ?
Choix : OAuth via navigateur (pas de token manuel)

Pourquoi :

✅ Plus simple pour l'utilisateur (pas de token à générer/copier/coller)

✅ Plus sécurisé (token stocké par le gestionnaire d'identifiants)

✅ Correspond à la maquette : bouton "S'authentifier" → ouvre navigateur

Flux OAuth :

Clic sur "S'authentifier" → ouvre https://github.com/login/oauth/authorize

Utilisateur autorise l'app

GitHub redirige vers http://localhost:xxxx/callback avec un code

L'app échange le code contre un token

Token stocké dans parametresCoursServer.json → remote.git.token

À implémenter :

Serveur OAuth temporaire dans le main process (écoute sur un port local)

Callback pour récupérer le token

Suppression du champ token manuel dans l'interface

2. Site source : fixe ou configurable ?
Choix : Configurable par l'utilisateur

Deux champs dans l'interface :

Dépôt source (ex: scse972/cours-interactifs)

Branche source (ex: main)

Pourquoi :

L'utilisateur peut vouloir copier n'importe quel repo public

Flexibilité maximale

Correspond à ta maquette où ces champs sont modifiables

Valeur par défaut : pré-remplie avec ton repo par défaut
